安装与首次使用
  1. 打开下载的 DMG，将 Foldlight 拖入 Applications，再从“应用程序”打开。
  2. 若系统阻止打开，确认下载来源后，前往“系统设置 → 隐私与安全性”查看“仍要打开”，按提示确认。 Apple 说明 ↗
  3. 点击“开启实时效果”，允许屏幕录制；若系统要求，请重新打开 App。
  4. 保持日常屏幕角度，点“当前位置归零”。⌃⌥⌘D 可随时暂停或开启。

合盖感应取决于设备是否提供可用传感器；不支持的型号仍可手动预览。已在 Mac14,6 / macOS 27 上实测，其他组合尚未完成实机验证。

桌面画面仅在本机处理，不保存、不上传。大角度下建议先暂停，再进行精确点击。

Beta · 需要 Shizuku。效果显示在 App 内，不替换系统桌面或其他 App。

图片版 · 安装与使用
  1. 下载 APK 并安装“折光 Fold”。现有用户可以直接覆盖升级，保留图片与参数。仅在系统提示时允许本次安装来源。
  2. 从官方渠道安装 Shizuku，通过无线调试或电脑启动。无需 Root；请使用调试模式启动。
  3. 打开折光 Fold，点“启用免 USB 感应”，允许此 App 的 Shizuku 授权，等待手机本地辅助连接。
  4. 选择内、外屏图片，点“全屏体验”。双指同时长按约 0.65 秒打开设置；配置完成后无需保持 USB 连接。

Shizuku 官方使用指南 ↗

重启手机后需重新启动 Shizuku。若感应停止，先检查 Shizuku 是否运行及该 App 是否已授权。

六项参数：外屏展开变暗 / 折叠变亮角度，内屏左侧展开变亮 / 折叠变暗角度，外屏右侧压缩和模糊程度。支持自动保存及恢复默认；内屏右半边保持清晰、静止。

全屏时维持双屏运行，合拢后内屏也可能保持供电。双指长按返回设置或退出 App 可结束体验。请勿与全局版同时开启双屏效果。

全局版 · 安装与使用
  1. 先暂停图片版的全屏效果，再安装“折光·全局实验”。两款 App 的图片、参数与授权相互独立。
  2. 先启动 Shizuku，再打开全局版，点“1 授权连续角度”并允许它的独立授权。
  3. 点“2 授权屏幕效果”，在系统无障碍设置的已安装应用中启用“折光·全局实验”，然后返回 App 开启全局效果。
  4. 完全合拢一次，解锁外屏并打开浏览器，再缓慢展开。设置页提供六项参数、自动保存和恢复默认。

Shizuku 官方使用指南 ↗

停止方式：回到全局版设置页点“暂停全局效果”，或锁屏。画面中没有悬浮按钮。配置完成后可断开 USB；手机重启后需重新启动 Shizuku。

Shizuku 读取屏幕并迁移当前 App，无障碍服务显示效果层。截图只在本机内存中处理，不保存、不上传。双屏持续点亮会增加耗电。

全屏体验指南

iPhone · 隐藏浏览器地址栏

  1. 用 Safari 打开折光如果在微信等 App 内，请先选择“在 Safari 中打开”。
  2. 分享 → 添加到主屏幕点方框向上箭头的“分享”；部分版本需先点“…”再点“分享”。
  3. 确认添加若出现“作为网页 App 打开”，保持开启，再点“添加”。
  4. 从桌面图标重新打开开启手机感应，再点“全屏体验”。无需从 App Store 下载。
找不到“添加到主屏幕”？

向下滚动分享菜单。若仍没有，点“编辑操作”把它加入菜单。

随时回到操作界面

轻点画面即可返回；电脑也可按 Esc。

网页内沉浸会隐藏本站控件；浏览器地址栏可能仍然保留。
