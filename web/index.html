FOLDLIGHT FOR FOLD8

随开合。光影流转。

内外双屏分别选图，透视、磨砂与亮度随开合变化。

下载 Fold8 测试版

0.3.6 · 5.8 MB · APK

已实测：SM-F9710 · Android 17 · One UI 9。其他机型和固件尚未验证。

需要 Shizuku 授权。只呈现 App 内的图片效果，不替换系统桌面或其他 App 的动画。

安装与免 USB 使用
  1. 下载 APK 并安装“折光 Fold”。如有提示，只允许用于安装的浏览器或文件管理器安装此文件；已有版本可直接覆盖升级。
  2. 从官方渠道安装 Shizuku，按管理器内的引导通过无线调试配对并启动，也可连接电脑启动。 Shizuku 官方下载与指南 ↗
  3. 打开折光 Fold，点“启用免 USB 感应”并允许 Shizuku 授权；确认“手机本地辅助已连接”后，选择“跟随开合”。
  4. 分别选择内、外屏图片，点“全屏体验”后缓慢开合。双指同时长按约 0.65 秒呼出设置。配置完成后，运行无需 USB。

手机重启后需要重新启动 Shizuku；首次无线配对请按官方指南完成，本项目已验证的是配置后的免 USB 运行。

按外屏、内屏左半边分组：展开和折叠分别调节变形起始角、速度、幅度、加速度及亮度起点。每块屏幕的磨砂强度与渐变强度均可独立设为 0–100%。内屏右半边保持清晰、静止。

全屏体验期间保持双屏运行，完全合拢也会维持内屏供电。结束体验请双指长按返回设置，或退出 App，以释放双屏保持。

FOLDLIGHT FOR MAC

合上屏幕。桌面随之转动。

在菜单栏安静运行，为实时桌面带来合盖效果。

0.2.4 · 1.8 MB · macOS 13+

Apple Silicon & Intel

测试版 · 尚未经过 Apple 公证，首次打开可能需要在系统设置中确认。

安装与首次使用
  1. 打开下载的 DMG，将 Foldlight 拖入 Applications，再从“应用程序”打开。
  2. 若系统阻止打开，确认下载来源后，前往“系统设置 → 隐私与安全性”查看“仍要打开”，按提示确认。 Apple 说明 ↗
  3. 点击“开启实时效果”，允许屏幕录制；若系统要求，请重新打开 App。
  4. 保持日常屏幕角度，点“当前位置归零”。⌃⌥⌘D 可随时暂停或开启。

合盖感应取决于设备是否提供可用传感器；不支持的型号仍可手动预览。已在 Mac14,6 / macOS 27 上实测，其他组合尚未完成实机验证。

桌面画面仅在本机处理，不保存、不上传。大角度下建议先暂停，再进行精确点击。

全屏体验指南

iPhone · 隐藏浏览器地址栏

  1. 用 Safari 打开折光如果在微信等 App 内，请先选择“在 Safari 中打开”。
  2. 分享 → 添加到主屏幕点方框向上箭头的“分享”；部分版本需先点“…”再点“分享”。
  3. 确认添加若出现“作为网页 App 打开”，保持开启，再点“添加”。
  4. 从桌面图标重新打开开启手机感应，再点“全屏体验”。无需从 App Store 下载。
找不到“添加到主屏幕”？

向下滚动分享菜单。若仍没有，点“编辑操作”把它加入菜单。
