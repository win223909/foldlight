Foldlight · Android Fold — Global edition
0.2.4

Global edition tested only on Samsung Fold8 (SM-F9710). Global effects on Fold7 and other models are untested; this build does not enable dual-screen sessions on those models.

Beta · Browser use has been verified. Content briefly freezes during transitions; this is not live video. Home, Recents, landscape and protected pages are not supported.

Global edition · Install and use
1. Stop the photo edition first, then install Foldlight Global Experiment. The two apps keep separate pictures, settings and permissions.
2. Start Shizuku, open the global edition, then tap permission button 1 and approve this app separately. App labels are currently in Chinese.
3. Tap permission button 2. Enable Foldlight Global Experiment under installed apps in Android Accessibility settings, then return and tap the blue enable button.
4. Close the phone fully once, unlock the cover and open a browser, then unfold slowly. The settings page has six controls, automatic saving and Restore defaults.

Shizuku: https://shizuku.rikka.app/guide/setup/

Six controls: cover opening dark-start and closing light-start angles; inner-left opening light-start and closing dark-start angles; cover right-edge compression and blur. Settings save automatically and can be reset. The inner right half stays clear and stationary.

To stop, return to the global app settings and tap the blue pause button, or lock the phone. There are no floating buttons. USB is not needed after setup; restart Shizuku after rebooting.

Shizuku captures the screen and moves the current app between displays; Accessibility hosts the effect layers. Screenshots stay in device memory and are neither saved nor uploaded. Keeping both panels powered uses more battery.

Defaults: cover 80° / 90°; inner left 55° / 70°; right-edge compression 60%; blur 55%. Settings are stored separately by each app.

Troubleshooting: check the model scope above, confirm Shizuku is running and this app is separately authorized. The global edition also needs its Accessibility service enabled. If no effect appears, pause, close fully, unlock and try again. Firmware updates can affect compatibility.

This is a downloadable beta APK signed with the existing development key for update continuity. A self-built APK uses your own key and may not update the hosted version in place.
