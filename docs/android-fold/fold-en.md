Foldlight · Android Fold — Photo edition
0.3.8-fold7.1

Photo edition tested on Samsung Fold7 (SM-F9660 / Android 16 / One UI 8.5) and Fold8 (SM-F9710 / Android 17 / One UI 9). Other models and firmware are untested.

Beta · Requires Shizuku. Effects stay inside this app; they do not replace the home screen or other apps.

Photo edition · Install and use
1. Download the APK and install Foldlight Fold. Existing users can update in place, keeping pictures and settings. If prompted, allow installation from this source.
2. Install Shizuku from its official source and start it through wireless debugging or a computer. Root is not required; use debugging mode.
3. Open Foldlight Fold. Tap the USB-free sensing button below the blue fullscreen button, approve this app in Shizuku, and wait for the local helper to connect. App labels are currently in Chinese.
4. Choose separate cover and inner pictures, then tap the blue fullscreen button. Hold two fingers together for about 0.65 seconds to open settings. USB is not needed after setup.

Shizuku: https://shizuku.rikka.app/guide/setup/

Restart Shizuku after rebooting your phone. If motion stops, check that Shizuku is running and this app is authorized.

Six controls: cover opening dark-start and closing light-start angles; inner-left opening light-start and closing dark-start angles; cover right-edge compression and blur. Settings save automatically and can be reset. The inner right half stays clear and stationary.

Fullscreen keeps both panels powered, including the inner panel when closed. Hold two fingers to return to settings, or leave the app to end the session. Do not enable both editions at the same time.

Defaults: cover 80° / 90°; inner left 55° / 70°; right-edge compression 60%; blur 100%. Settings are stored separately by each app.

Troubleshooting: check the model scope above, confirm Shizuku is running and this app is separately authorized. The global edition also needs its Accessibility service enabled. If no effect appears, pause, close fully, unlock and try again. Firmware updates can affect compatibility.

This is a downloadable beta APK signed with the existing development key for update continuity. A self-built APK uses your own key and may not update the hosted version in place.
